# Online Student Result Management System

An online web-based Student Result Management System designed to manage and display student academic results efficiently.

## 📌 About the Project

The Online Student Result Management System provides a simple interface for managing student information, marks, and examination results.

The system helps students view their results and allows result-related data to be managed in an organized way.

## ✨ Features

- Student Login
- View Student Results
- Student Profile
- Display Subject-wise Marks
- Calculate/Display Total Marks
- Display Percentage
- Result Status
- Simple and User-Friendly Interface
- Responsive Web Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
